# HamStore Studio

แก้ข้อความและรูปของเว็บได้โดยไม่ต้องแตะโค้ด

```bash
npm run studio      # เปิด http://localhost:4321
```

หน้าเว็บจริงเป็น static export ไม่มีเซิร์ฟเวอร์ของตัวเอง — studio จึงเป็นเซิร์ฟเวอร์แยก
ที่อ่าน/เขียน `content/site.json` และรับรูปเข้า `public/uploads/` เท่านั้น
ไม่มี dependency เพิ่ม ใช้แค่ Node

## ขั้นตอนใช้งาน

1. `npm run studio` แล้วเปิด http://localhost:4321
2. แก้ข้อความ / ลากรูปมาวางในช่องรูป
3. กด **บันทึก** — ตรวจข้อมูลก่อนเขียนลงไฟล์ ถ้าผิดจะบอกว่าผิดตรงไหน
4. กด **สร้างเว็บใหม่** (หรือ `npm run build` เอง) แล้วเนื้อหาใหม่จะขึ้นในเว็บ
5. commit `content/site.json` กับรูปใน `public/uploads/` ที่อยากเก็บไว้

## แก้อะไรได้บ้าง

| ส่วน | แก้ได้ |
|---|---|
| ทั่วไป | ชื่อแบรนด์ เมนู ท้ายเว็บทั้ง 4 คอลัมน์ |
| หน้าร้าน | พาดหัว คำโปรย ปุ่ม รูปพื้นหลัง หัวข้อทุกส่วน แถบใหญ่ 2 แถบพร้อมรูป |
| ไอเทมในร้าน | ทั้ง 18 ชิ้น — ชื่อ คำอธิบาย ราคา ส่วนลด หมวด ระดับ **รูปปก** ผู้ทำ จำนวนคนที่มี ได้อะไรบ้าง โผล่ที่ไหน |
| ของที่แนะนำ | เลือกว่าจะแนะนำชิ้นไหน พร้อมเหตุผล |
| คลัง Asset | ทั้ง 18 ชิ้น — ชื่อ ผู้พัฒนา เวอร์ชัน ขนาด pipeline วันที่ **รูปปก** |

**ช่องรูปเว้นว่างได้** — เว้นไว้แปลว่าให้ระบบวาดปกให้เหมือนเดิม ใส่รูปเมื่อไหร่รูปจะทับทันที

สิ่งที่ยังอยู่ในโค้ด ไม่ได้อยู่ในนี้ คือเรื่องการออกแบบ — ลายปก สีประจำหมวด ไอคอน
และจังหวะอนิเมชั่น พวกนี้เป็นการตัดสินใจเชิงดีไซน์ ไม่ควรพิมพ์ลงช่องข้อความ

## เปิดให้คนอื่นเข้า

ค่าเริ่มต้นเปิดเฉพาะเครื่องตัวเอง (127.0.0.1) ถ้าตั้ง token จะเปิดรับจากเครื่องอื่นด้วย:

```bash
HAMSTORE_STUDIO_TOKEN=ตั้งรหัสยาวๆ npm run studio
# แล้วเข้า http://<host>:4321/?token=ตั้งรหัสยาวๆ
```

## ปลอดภัยแค่ไหน

- อัปโหลดได้เฉพาะไฟล์รูป (png/jpg/webp/gif/svg/avif) ไม่เกิน 8 MB
- ชื่อไฟล์ถูกล้างและใส่ timestamp กันชนกัน
- ตรวจข้อมูลก่อนเขียนเสมอ — ราคาติดลบ ชื่อว่าง id ซ้ำ หรือแนะนำไอเทมที่ถูกลบไปแล้ว จะถูกปฏิเสธ
- ทุกครั้งที่บันทึก จะสำรองไฟล์เดิมไว้ที่ `content/backups/` (เก็บ 20 เวอร์ชันล่าสุด)
