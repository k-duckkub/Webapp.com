# HamStore Studio

แก้ทุกอย่างของเว็บได้โดยไม่ต้องแตะโค้ด — ข้อความ รูป ราคา สี หมวด และรายการสินค้า

```bash
npm run studio      # เปิด http://localhost:4321
```

หน้าเว็บจริงเป็น static export ไม่มีเซิร์ฟเวอร์ของตัวเอง — studio จึงเป็นเซิร์ฟเวอร์แยก
ที่อ่าน/เขียน `content/site.json` และรับรูปเข้า `public/uploads/` เท่านั้น
ไม่มี dependency เพิ่ม ใช้แค่ Node

## ขั้นตอนใช้งาน

1. `npm run studio` แล้วเปิด http://localhost:4321
2. แก้ข้อความ / ลากรูปมาวางในช่องรูป
3. กด **บันทึก** — ตรวจข้อมูลก่อนเขียนลงไฟล์ ถ้าผิดจะบอกว่าผิดตรงไหน
4. กด **สร้างเว็บใหม่** (หรือ `npm run build` เอง) แล้วเนื้อหาใหม่จะขึ้นในเว็บ
5. commit `content/site.json` กับรูปใน `public/uploads/` ที่อยากเก็บไว้

## แก้อะไรได้บ้าง

| ส่วน | แก้ได้ |
|---|---|
| ทั่วไป | ชื่อแบรนด์ เมนู ท้ายเว็บทั้ง 4 คอลัมน์ |
| หน้าร้าน | พาดหัว คำโปรย ปุ่ม รูปพื้นหลัง หัวข้อทุกส่วน แถบใหญ่ 2 แถบพร้อมรูป |
| ไอเทมในร้าน | **เพิ่ม ลบ ทำซ้ำ สลับลำดับ** · ชื่อ คำอธิบาย ราคา ส่วนลด หมวด ระดับ **สีปก 2 สี** รูปปก ผู้ทำ จำนวนคนที่มี ได้อะไรบ้าง โผล่ที่ไหน |
| ของที่แนะนำ | เลือกชิ้นไหนก็ได้ พร้อมเหตุผล |
| Unity Asset | **เพิ่ม ลบ ทำซ้ำ สลับลำดับ** · ชื่อ ผู้พัฒนา เวอร์ชัน ขนาด pipeline ราคา ส่วนลด หมวด License **สีปก** รูปปก ตั้งเป็นซื้อแล้ว/ยัง |
| ตะกร้า | ข้อความทุกบรรทัดในแผงตะกร้า |
| หมวดและระดับ | **เพิ่ม ลบ สลับลำดับหมวด** · ชื่อ **ไอคอน** **ลายปก** **สี** ทั้งหมวดไอเทม ระดับความหายาก และหมวด Unity Asset |
| ขั้นตอนหน้าแรก | เพิ่ม ลบ แก้ทั้งสามขั้น พร้อมไอคอนและสี |
| ตั้งค่า | เหรียญตั้งต้น จำนวน asset ต่อหน้า หมวดที่ขึ้นชั้นล่างหน้าแรก |

**ช่องรูปเว้นว่างได้** — เว้นไว้แปลว่าให้ระบบวาดปกให้เหมือนเดิม ใส่รูปเมื่อไหร่รูปจะทับทันที

## วิธีที่เร็วที่สุด: วางลิงก์รูป

ช่องรูปรับ URL เต็มได้ ไม่ต้องโหลดไฟล์มาเก็บเลย

1. ไปที่ [Unsplash](https://unsplash.com) หรือ [Pexels](https://pexels.com) — ใช้เชิงพาณิชย์ได้ ไม่ต้องให้เครดิต
2. ค้นคำอย่าง `t-shirt product`, `cushion`, `table lamp`
3. คลิกขวาที่รูป → คัดลอกที่อยู่รูปภาพ
4. วางลงช่องรูปของไอเทมนั้นใน studio
5. กด **บันทึก** แล้ว **สร้างเว็บใหม่**

**เก็บลิงก์มาทีเดียวหลายอันก็ได้** — ในหน้า studio มีช่อง “วางลิงก์รูปทีเดียวหลายอัน”
วางบรรทัดละหนึ่ง URL มันจะไล่ใส่ตามลำดับไอเทม และ**แสดงให้ดูก่อนว่าอันไหนไปไอเทมไหน**
ก่อนกดยืนยัน ถ้าอยากระบุเองก็ใส่เลขไอเทมข้างหน้า เช่น `3 https://…`

หรือจากเทอร์มินัล เก็บลิงก์ใส่ไฟล์แล้ว

```bash
node tools/import-photos.mjs links.txt --dry   # ดูก่อนว่าจับคู่ยังไง
node tools/import-photos.mjs links.txt
```

ถ้าลิงก์เสียหรือโฮสต์ล่ม การ์ดจะกลับไปใช้ภาพที่ระบบวาดให้เอง ไม่กลายเป็นกล่องเปล่า

## ใส่รูปถ่ายจริงทีเดียวหลายไฟล์

รูปปกที่มากับโปรเจกต์เป็นภาพที่วาดขึ้น ไว้ใช้ก่อนมีรูปถ่ายจริง
พอมีรูปจริงแล้ว — เสื้อ หมอน โคมไฟ ถ่ายเอง หรือโหลดจากคลังที่อนุญาต —
ใส่ทีเดียวทั้งชุดได้สองทาง

**ในหน้า studio** ลากไฟล์ทั้งกองมาวางบนแถบเหนือรายการ

**หรือทางคำสั่ง**

```bash
node tools/import-photos.mjs ~/photos            # หน้าร้าน
node tools/import-photos.mjs ~/photos --assets   # หน้า Unity Asset
node tools/import-photos.mjs ~/photos --dry      # ดูผลก่อน ไม่แก้อะไร
```

**ตั้งชื่อไฟล์ให้จับคู่ได้** เรียงตามลำดับที่ระบบลองก่อนหลัง

1. ขึ้นต้นด้วยเลขไอเทม — `3.jpg`, `07-lamp.jpg`, `item-3.png` (ชัดเจนที่สุด ใช้อันนี้)
2. มีชื่อไอเทมอยู่ในชื่อไฟล์ — `แฮมพ่อครัว.jpg`
3. จับคู่ไม่ได้ → มันจะบอกชื่อไฟล์นั้นออกมา ไม่เดาสุ่มใส่ให้

รูปเก่าไม่ถูกเขียนทับ ไฟล์ใหม่เข้าไปด้วยชื่อใหม่เสมอ ย้อนกลับด้วย
`git checkout content/site.json`

**เรื่องลิขสิทธิ์** — รูปจากเว็บแบรนด์ (เช่นที่เห็นใน Google Shopping) เอามาใส่ร้านไม่ได้
ถ้าไม่ได้ถ่ายเอง ใช้คลังที่อนุญาตให้ใช้เชิงพาณิชย์ เช่น Unsplash, Pexels, Pixabay

กด **ดูตัวอย่าง** เพื่อเปิดเว็บที่ build ล่าสุดในกรอบ สลับดูได้ทั้งสองหน้า

สิ่งที่ยังอยู่ในโค้ด คือเลย์เอาต์และจังหวะอนิเมชั่น — ลำดับของ section
บนหน้า ระยะห่าง และความเร็วของการเคลื่อนไหว พวกนี้เปลี่ยนแล้วต้องดูด้วยตา
ไม่ใช่พิมพ์ตัวเลขลงช่อง ส่วนไอคอนกับลายปกเลือกจากรายการที่มีอยู่จริงเท่านั้น
เพราะชื่อที่ไม่มีอยู่จะทำให้ปกว่างเปล่า

## เปิดให้คนอื่นเข้า

ค่าเริ่มต้นเปิดเฉพาะเครื่องตัวเอง (127.0.0.1) ถ้าตั้ง token จะเปิดรับจากเครื่องอื่นด้วย:

```bash
HAMSTORE_STUDIO_TOKEN=ตั้งรหัสยาวๆ npm run studio
# แล้วเข้า http://<host>:4321/?token=ตั้งรหัสยาวๆ
```

## ปลอดภัยแค่ไหน

- อัปโหลดได้เฉพาะไฟล์รูป (png/jpg/webp/gif/svg/avif) ไม่เกิน 8 MB
- ชื่อไฟล์ถูกล้างและใส่ timestamp กันชนกัน
- ตรวจข้อมูลก่อนเขียนเสมอ และบอกทีละจุดว่าผิดตรงไหน — ราคาติดลบ ชื่อว่าง id ซ้ำ
  สีที่ไม่ใช่ `#rrggbb` ไอคอนหรือลายปกที่ไม่มีอยู่จริง ไอเทมที่ชี้ไปยังหมวดที่เพิ่งลบ
  แถบใหญ่หรือชั้นล่างที่อ้างหมวดที่หายไป และของแนะนำที่ชี้ไปยังไอเทมที่ถูกลบ
- การลบถามยืนยันก่อนเสมอ และบอกชื่อสิ่งที่จะหายไป
- ทุกครั้งที่บันทึก จะสำรองไฟล์เดิมไว้ที่ `content/backups/` (เก็บ 20 เวอร์ชันล่าสุด)
